# todo-list-js
html, css, javascript를 활용해 구현한 todolist 과제입니다.
배열을 중심으로 화면과 로컬스트리지가 동기화되도록 작성했습니다.

구현 기능
1. 할 일 입력 및 추가, date.now()를 활용해 고유 id부여 , 빈 값 입력시 예외처리.
2. 로컬스트리지 연동해 데이터 저장, 새로고침 시 이전 목록 복원, 데이터 변경 시 실시간 동기화.
3. 이벤트 위임 활용, 개별 버튼이 아닌 부모 요소에 이벤트를 추가해 메모리 최적화, 완료 버튼 클릭 시 classlist 제어를 통해 취소선 구현, 삭제 클릭시 filter() 통해 데이터 및 ui 제거.

핵심 적용 기술
1. 로컬스트리지는 문자열 데이터만 저장가능하니 json.stringfy(),json.parse() 활용
2. 할 일이 추가될 때마다 이벤트 리스너를 추가하는건 낭비와 버그 유발할 수 있으니 부모 노드에 이벤트 하나만 등록하여 이벤트 버블링 특성 활용해 e.target 으로 클릭된 자식 노드(완료,삭제 버튼)를 감지하여 처리하도록 구현.
3. dom을 직접 수정하여 상태를 관리하는 대신 todos 리스트를 조작한 뒤 rendertodos() 함수를 호출하여 화면을 처음부터 다시 그리는 방식으로 작성해
데이터와 화면의 싱크가 깨지는 현상 방지
